## 핵심 개념

**정적 할당 vs 동적 할당**
- 정적 할당: 프로그램 실행 전에 메모리 할당 크기가 정해지고, 실행 도중 크기가 변하지 않는 방식(코드 작성 단계에서 크기가 정해져서, 실행할 때마다 항상 같은 크기로 할당됨)
- 동적 할당: 프로그램 실행 단계에서 결정되는 크기에 따라 메모리를 할당하는 방식
- 메모리 사용을 위해서는 "할당"과 "해제" 과정이 반드시 필요함

**malloc**
- 함수 원형: `void *malloc(unsigned int size);`
- 인자: 할당받을 메모리 크기(바이트 단위)
- 반환값: 할당받은 메모리의 시작 주소(성공 시), 실패 시 `NULL`
- 반환 타입은 `void*`(범용 포인터) — 반환값이 없다는 뜻의 `void`와 혼동하면 안 됨
- 동적 할당된 메모리는 이름이 없기 때문에 반드시 포인터 변수에 연결해서 사용해야 함

```c
int *p = NULL;              // 동적 메모리 접근을 위한 포인터 변수
p = (int *)malloc(sizeof(int));  // 동적 메모리 할당
free(p);                    // 동적 메모리 해제
```

**free**
- 함수 원형: `void free(void *ptr);`
- 인자: 해제할 메모리 공간을 가리키는 포인터 변수
- 기능: `ptr`이 가리키는 메모리를 해제함

**calloc**
- 함수 원형: `void *calloc(unsigned int num, unsigned int size);`
- 인자: `num`(할당받을 원소 개수), `size`(원소 하나의 크기, 바이트 단위)
- 반환값: `num*size` 바이트만큼 할당하고, 할당된 메모리를 모두 0으로 초기화한 뒤 시작 주소 반환. 실패 시 `NULL`

```c
int *p = NULL;
p = (int *)calloc(5, sizeof(int));  // 크기가 5인 int형 배열 할당(0으로 초기화됨)
```

**realloc**
- 함수 원형: `void *realloc(void *ptr, unsigned int size);`
- 인자: `ptr`(크기를 변경할 메모리의 시작 주소), `size`(변경 후 메모리의 전체 크기, 바이트 단위)
- 반환값: `ptr`이 가리키는 메모리 크기를 `size` 바이트로 조정하고, 조정된 메모리의 시작 주소 반환. 실패 시 `NULL`
- 주의: 기존 위치에서 새로운 크기를 확보할 수 없으면, 기존 공간을 해제하고 새로운 위치에 다시 할당함 → 그래서 반환된 주소가 원래 주소와 다를 수 있음

```c
char *p = (char *)malloc(5);   // 5바이트 할당
p = (char *)realloc(p, 10);    // 10바이트로 크기 변경
```
