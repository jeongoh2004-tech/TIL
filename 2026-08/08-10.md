## 핵심 개념

**`fgetc`/`fputc`의 반환형이 `int`인 이유**
- 문자 하나(0~255)뿐 아니라 파일의 끝을 나타내는 EOF(-1)까지 반환해야 하기 때문에, `char`가 아니라 `int`로 반환값을 받음
- `feof()`와 함께 파일을 문자 단위로 복사하는 대표적인 패턴:
```c
int ch = fgetc(fp2);
while (!feof(fp2)) {
    fputc(ch, fp1);
    ch = fgetc(fp2);
}
```

**이진 파일 입출력 — `fwrite`, `fread`**
```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *fp);
size_t fread(void *ptr, size_t size, size_t count, FILE *fp);
```

| 인자 | 의미 |
|---|---|
| `ptr` | 쓸/읽을 데이터가 있는 메모리 주소 |
| `size` | 데이터 항목 하나의 크기(바이트) — 보통 `sizeof(자료형)` |
| `count` | 몇 개 항목을 처리할지 |
| `fp` | 파일 포인터 |
